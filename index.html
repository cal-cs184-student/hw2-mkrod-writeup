de Casteljau Algorithm

The de casteljau algorithm is a recursive algorithm that takes a vector set of control points defining a bezier curve and continuously interpolates along each vector using a parameter. Each time step trims off the set of control points by 1 until a single control point is left which is guaranteed to lie on the bezier curve at the parameter used. I implemented the time step function by initializing an empty vector of control points and looping through the given set of points. I interpolated across each pair of control points and appended the value to the return array up until the second to last element since the array we are using doesn't have a value past the last element. If it turns out the input array contains exactly 1 element, we return the array with one element since this marks the end of the de Casteljau algorithm.

How de Casteljau extends to Bezier Surfaces

The de Casteljau algorithm extends to 3 dimensional surfaces with a concept known as a tensor product. Since a bezier surface, or patch, is defined by a 2D grid of control points, we use 2 parameters (u, v) to evaluate across the dimensions. Put simply, we go through standard 1D interpolatation on each dimension separately. Once applied to every row in our 2D grid of control points using u, our grid shrinks to a single column of control points that we interpolate across again, this time with parameter v.

How it was implemented

So we started by implementing a de Casteljau step algorithm to use as a helper in a separate function that ran this step function on a set of 3D vectors until left with a single point. The final evaluate function uses this evaluate1D function to run de Casteljau on each row of the 2D grid of control points with the given parameter u and store each flattened value in a separate vector of 3D points. Finally, the function evaluates the newly created vector at v to find the single point on the bezier patch.
